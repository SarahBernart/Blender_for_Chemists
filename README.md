# Blender_for_Chemists
Blender python scripts for Slab Visualizations

This project enables realistic 3D visualization of atomic structures in Blender, based on .xyz files typically generated from DFT or molecular dynamics simulations. It is tailored for researchers and creatives working in the fields of catalysis, surface chemistry, and materials science.

The setup allows for fast and flexible rendering of scientific structures with custom materials and precise control over appearance. Whether you're preparing images for presentations, papers, or educational content, this tool helps bring your atomic models to life.

This tool is designed for:
- Computational chemists and physicists
- Catalysis and surface scientists
- Educators and students in nanoscience and materials research
- Blender users seeking to visualize atomic-level structures in a realistic style

Your .xyz file should be structured with:
- Element name and x/y/z coordinates per line
- Optional frame separation if visualizing multiple steps
